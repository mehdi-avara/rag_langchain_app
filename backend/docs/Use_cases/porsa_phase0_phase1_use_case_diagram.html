Each role has a distinct set of RBAC permissions. As owner/admin you can test every flow. Here's how to test as each user type.

👑
System Admin
Full access — you, the owner

Has all permissions including:

currencies:manage purchase_management:orders:approve supplier_management:create material_management:import requisition_management:approve warehouse_management:stock:manage financial:export

🧪 How to test as Admin:

  1. Login as admin / admin123 (seed credentials)
  2. Go to Currency Settings → add IRT + USD, set exchange rate
  3. Create a Purchase Order → add phases + items → submit for approval → approve it
  4. Check Financial Dashboard shows the PO spend
  5. Create a Supplier, add contacts and an evaluation
  6. Create Items in Material Master
  7. Create a Warehouse, Zone, and Storage Locations
  8. Create a GRN against the PO → Post it → verify stock appears
💼
Finance Manager
Sees money — dashboards, receipts, exports

Key permissions:

financial:read financial:export exchange_rates:create purchase_management:summary purchase_management:costs:manage purchase_management:orders:approve

🧪 How to test as Finance:

  1. Open Financial Dashboard → verify KPI cards, cashflow chart
  2. Enter a new exchange rate (e.g. today's USD/IRT)
  3. Add a freight cost to a PO
  4. Link a financial receipt to a PO
  5. Export a report to Excel and PDF
  6. Verify you cannot approve a PO (403 if not granted)
🛒
Procurement Officer
Creates POs, RFQs, manages suppliers

Key permissions:

purchase_management:orders:create purchase_management:phases:manage supplier_management:create rfq_management:create rfq_management:approve requisition_management:read purchase_management:orders:approve

🧪 How to test as Procurement:

  1. View list of approved MRs → pick one
  2. Create an RFQ from the MR → assign 2 suppliers
  3. Record quotation responses for each supplier
  4. Open the comparison table → select winning bid
  5. Create a PO, add phases + line items → submit for approval
  6. Search POs by keyword ("pump") and semantic
🏭
Warehouse Manager
Receives goods, manages stock

Key permissions:

warehouse_management:locations:manage warehouse_management:stock:manage warehouse_management:movements:create goods_receipt_management:create goods_receipt_management:approve material_management:create

🧪 How to test as Warehouse:

  1. Create a Warehouse → Zone → Storage Location
  2. Create a GRN against an approved PO phase
  3. Fill in accepted/rejected quantities per item
  4. Post GRN → check stock levels updated automatically
  5. Issue stock for a work order → verify deduction
  6. Run a stock count → post it → see adjustment movements
  7. Check low-stock alerts list
📋
Department Requester
Raises requisitions for their dept

Key permissions:

requisition_management:create requisition_management:read material_management:read material_management:search requisition_management:approve

🧪 How to test as Requester:

  1. Create an MR (priority: Urgent, reason: breakdown)
  2. Search Item catalog → add 3 line items with estimated cost
  3. Submit the MR
  4. Track MR status — changes to "Under Review"
  5. After dept head approves → status becomes "Approved"
  6. Verify you cannot approve your own MR (403)
🤖
AI Assistant (Chat)
Runs with caller's permissions — no more

Available to all users with the right permissions:

supplier_management:ask material_management:ask requisition_management:ask rfq_management:ask goods_receipt_management:ask warehouse_management:ask purchase_management:orders:ask

🧪 How to test the AI chat:

  1. Open the Chat page (primary interface)
  2. Ask: "What's my current stock of 6-inch gate valves?"
  3. Ask: "Which supplier gave the best quote for pumps last month?"
  4. Ask: "Show me open POs above $50,000"
  5. AI shows a draft action → you confirm or cancel it
  6. Verify it respects your role — no actions you lack permission for

The two end-to-end procurement flows showing how every module connects. Money flows through multi-currency at every step.

🔄 Full Procurement Flow: MR → RFQ → PO → GRN → Stock

Requester Create MR (Draft) → Submit MR → Dept Head Approves MR status: Approved
Procurement Create RFQ from MR → Assign suppliers → Record quotations → Select winner
Procurement Create PO + phases → Submit for approval → Manager Approves PO → Mark phase Ordered/Shipped
Warehouse Create GRN (Draft) → Fill accepted/rejected qty → Post GRN → Celery Event → → RECEIPT StockMovement
Warehouse Stock level ↑ → Weighted avg cost updated → PO → Received/Closed

💱 Multi-Currency Money Flow (at every step)

Transaction in any currency → Look up exchange rate ≤ date → Store 4 columns amount · currency_id · amount_base · exchange_rate_used
Dashboard aggregates ← All in base currency (IRT) Rate is frozen — never recalculated after the fact

📦 Stock Issue Flow (warehouse → work order)

Warehouse Issue Stock (qty, item, location) → Check available ≥ requested → ISSUE StockMovement (append-only) → Stock level ↓

📤 Export Flow (any module)

POST /{module}/{entity}/export → 202 + task_id → Celery generates xlsx/csv/pdf → Poll GET /tasks/{id} → download_url

🔒 RBAC Flow (every request)

Request arrives → Authenticate (JWT/session) → require_permission("module:action") → Has permission?
✅ Yes → proceed | ❌ No → 403 PERMISSION_DENIED
