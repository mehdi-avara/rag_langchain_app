AI Assistant Backbone
The chat page is the system's primary interface, built as a stateful agent (master plan §12). Each phase adds a parallel AI sub-phase that wraps that phase's service functions as agent tools (Module Tool Contract §12.4). The agent runs with exactly the caller's RBAC.
KPI & Reporting sub-phase
After each delivery phase, a Phase-R sprint adds /reports, /kpi and /ask endpoints, a summary page (KPI cards + charts), and Excel/CSV/PDF export — so managers get visibility per phase.
Foundational rules (always on)
Alembic owns the schema · every route permission-protected & seeded in RBAC · heavy work (>200ms) → Celery · catalogued errors only · 4-column money fields · schema-per-module, no cross-module Python imports (FKs OK).
